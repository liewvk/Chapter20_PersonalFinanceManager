# Chapter 20 - Personal Finance Manager

A C++ application for managing personal finances.

## Overview

This project provides tools and utilities for tracking and managing personal financial data.

## Technologies

- **C++** - Core application language
- **CMake** - Build system

## Building

To build this project:

```bash
mkdir build
cd build
cmake ..
make
```

## Features

- Personal finance management
- Financial tracking and reporting
